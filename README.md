Welcome to my personal website! This application showcases my professional background, research, and includes a dynamic React Dashboard demonstrating my expertise in modern web development.

**🔗 [View Live Site](https://joshua-martin.com)**

## ✨ Features

- 👨‍💼 **Personal Background**: Professional overview and employment history
- 📊 **Interactive Dashboard**: Widgets showcasing full-stack development expertise
- 📄 **Resume**: Comprehensive CV with downloadable option
- 🔬 **Research**: Collection of papers on feature extraction, dimensionality reduction, and cryptography
- 🌓 **Theming**: Toggle between light and dark modes

## 🛠️ Technologies Used

- **React**: Core framework for building the UI
- **Redux Toolkit**: For efficient state management
- **TypeScript**: Adding static typing for improved code quality
- **React Hooks**: Managing state and side effects
- **Context API**: Handling global state (user session, theme)
- **React Router**: Seamless navigation between views
- **Chart.js & React-Chartjs-2**: Creating stunning data visualizations
- **Tailwind CSS**: Utility-first CSS framework for modern design

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn

### Environment Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Shmartin1/react-dashboard-app.git
   cd react-dashboard-app
   ```

2. Set up environment variables:
   ```bash
   cp .env.example .env
   ```
   Open `.env` and replace `your_weather_api_key_here` with your [OpenWeatherMap API key](https://openweathermap.org/api).

3. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

4. Start the development server:
   ```bash
   npm start
   # or
   yarn start
   ```

5. Open your browser and navigate to `http://localhost:3000`

## 🧭 Site Navigation
